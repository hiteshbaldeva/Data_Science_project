1. High-Level Architecture Overview

The pipeline takes raw dual-sensor recordings from an EKO DUO ECG+ digital stethoscope placed sequentially at four chest auscultation locations (Mitral/APEX, Tricuspid/LLSB, Pulmonary/LUSB, Aortic/RUSB) and transforms them into patient-level risk predictions for Heart Failure with Reduced Ejection Fraction (HFrEF, LVEF ≤ 40%).

Raw Stethoscope Signals (30s Synchronous ECG + PCG across 4 Auscultation Sites) ├── 1. Continuous Signal Preprocessing (Resampling + Zero-Phase Butterworth + Mains Notch Filter) ├── 2. Physiological Gating (Pan-Tompkins R-Peak Detection -> Anchored [t_R - 0.25s, t_R + 1.25s] Slices) ├── 3. Feature Representations (PCG -> 32-Band Log-Mel 2D Spectrogram; ECG -> Normalized 1D Vector) ├── 4. Dual-Branch Encoders (PCG 2D ConvNet + ECG 1D Conv-Residual Encoders -> Latent Sequences) ├── 5. Level 1 Fusion: Inter-Modality Cross-Attention (Q_ECG x K/V_PCG -> Detects EMAT Timing Delay) ├── 6. Level 2 Fusion: Inter-Site Spatial Fusion (Multi-Head Self-Attention across APEX, LLSB, LUSB, RUSB) └── 7. Feature-Decision Double-Level Multi-Heads (6 Simultaneous Supervisions -> Ensembled Prediction)

2. Stage-by-Stage Detailed Preprocessing

Stage 1: Continuous Full-Recording Filtering & Caching

Raw 30-second recordings are processed as continuous waveforms before any window slicing occurs:

  • Acoustic PCG Stream:
    • Polyphase Rational Resampling: Resampled to 1440 Hz using polyphase filtering (scipy.signal.resample_poly) to avoid phase artifacts.
    • Zero-Phase Butterworth Bandpass: 5th-order filter passing 20 Hz to 400 Hz using forward-backward filtering (sosfiltfilt). This strips respiratory breath sounds (<20 Hz) and ambient room hiss (>400 Hz) with zero phase distortion.
  • Electrical ECG Stream:
    • Sampling Rate: Maintained at 500 Hz (standard clinical tracing resolution).
    • Mains Interference Filter: IIR notch filter at 50 Hz (Q = 30) removes powerline hum.
    • Baseline Wander Removal: 3rd-order Butterworth bandpass filter (0.5 Hz to 40 Hz) removes respiration-induced baseline sway for clean R-peak detection.
  • Flat Memory-Mapped Cache: Signals are stored sequentially in pcg.npy and ecg.npy. Metadata records per-recording coordinates (pcg_offset, ecg_offset), enabling sub-millisecond retrieval.
Stage 2: ECG-Guided Physiological Gating

Instead of blind time-window slicing that chops cardiac cycles arbitrarily, the synchronized ECG acts as a physiological clock:

  • R-Peak Detection: Evaluates the 500 Hz lead-I ECG via derivative and moving-average integration (Pan-Tompkins) to locate all ventricular depolarization peaks (tR).
  • Anchored Window Slicing:
    Window Bounds = [tR - 0.25 s,   tR + 1.25 s]    (Fixed Duration: 1.50 seconds)
    • PCG Window Slice: Exactly 2,160 samples (1.50 s × 1440 Hz).
    • ECG Window Slice: Exactly 750 samples (1.50 s × 500 Hz).
  • Acoustic Quality Control: Evaluates the analytic envelope (Hilbert transform) to detect S1 and S2 heart sounds. Low-RMS windows (<0.005) or clipped microphone friction artifacts are discarded.
Stage 3: Window Feature Representation per Site

Each valid cardiac window is converted into optimal feature spaces for deep learning:

  • PCG Stream → 32-Band Time-Frequency Log-Mel Spectrogram:
    • STFT Analysis: 128-point Hann window with a 64-sample hop size (50% overlap).
    • Mel Filterbank: 32 triangular filterbanks spanning 20 Hz to 700 Hz.
    • Logarithmic Dynamic Compression: Log-Mel = log(max(Mel, 1e-6)).
    • Per-Spectrogram Standardization: Normalized to zero mean and unit variance.
    • Output Tensor Shape: (1, 32, 35) — 1 channel, 32 frequency bins, 35 time frames.
  • ECG Stream → 1D Temporal Standardization:
    • The 750-sample window is standardized: (x - mean) / std.
    • Output Tensor Shape: (1, 750) — Preserves sharp QRS spikes and ST-T segments.

3. Deep Multimodal & Multi-Site Fusion Mechanics

Level 1: Inter-Modality Cross-Attention (CCF / EMAT Detection)

In HFrEF, ventricular remodeling delays mechanical pressure buildup, causing prolonged Electromechanical Activation Time (EMAT) — the latency between the electrical Q-wave and the acoustic mitral S1 closure.

  • PCG Encoder: 3 Conv2d stages (channels 32 → 64 → 128) with BatchNorm, MaxPool2d, and AdaptiveAvgPool2d → yields sequence (B, 8, 128).
  • ECG Encoder: 3 Conv1d stages (kernels 15, 7, 5; channels 32 → 64 → 128) with BatchNorm, MaxPool1d, and AdaptiveAvgPool1d → yields sequence (B, 8, 128).
  • Bidirectional Multi-Head Cross-Attention:
    AECG→PCG = softmax(QECG · KPCGT / √d) · VPCG
    APCG→ECG = softmax(QPCG · KECGT / √d) · VECG
    The network queries the exact temporal correlation between electrical spikes and acoustic heart sounds.
  • Fused Site Embedding: Sequence is mean-pooled and projected → outputs 128-dimensional site vector: vsite ∈ ℝ128 (for APEX, LLSB, LUSB, and RUSB).
Level 2: 4-Site Auscultation Spatial Fusion (CSB)

Because stethoscope recordings are collected sequentially across chest sites, raw signals cannot be aligned chronologically across locations. The network fuses them at the high-level semantic representation level:

  • Stack 4 site embeddings: [vAPEX, vLLSB, vLUSB, vRUSB] → (B, 4, 128).
  • Inter-Site Multi-Head Self-Attention: Models spatial correlations across the four anatomical valves.
  • Noise Suppression: If one site (e.g. APEX) contains local rubbing noise, the model cross-references the clean Pulmonary, Aortic, and Tricuspid vectors, preventing false alarms.
  • Outputs the Channel-Shared Embedding: vCS ∈ ℝ128.
Level 3: Feature-Decision Double-Level Multi-Branch Heads
  • Individual Site Heads: 4 linear classifiers for APEX, LLSB, LUSB, and RUSB (Psite).
  • Shared Head: Evaluates inter-site representation (PCS).
  • Joint Multi-Branch Head: Evaluates concatenated multi-branch vector (Pjoint).
  • Deep Auxiliary Supervision: Total loss supervises all 6 heads simultaneously:
    ℒtotal = ℒAPEX + ℒLLSB + ℒLUSB + ℒRUSB + ℒCS + ℒjoint
  • Ensemble Decision: Final patient probability is the average of all 6 heads:
    Pfinal = (PAPEX + PLLSB + PLUSB + PRUSB + PCS + Pjoint) / 6
